# Textory

Textory — минималистичный Android-редактор Markdown с наглядным сравнением текущего текста и последнего сохранения. Это не Git-клиент: приложение хранит простую локальную историю без веток, авторов, хешей и серверной части.

## Возможности

- независимые Markdown-документы с созданием, импортом, переименованием и удалением;
- форматированный режим чтения и отдельный режим правки исходного `.md`;
- подсветка изменений на уровнях абзаца, фразы и слова;
- компактное сравнение «Сейчас / Было» и навигация между изменениями;
- локальные снимки при каждом сохранении, сравнение любой версии с живым черновиком и восстановление выбранного текста;
- сохранение импортированного файла и отдельный экспорт копии;
- нативное выделение всего документа и копирование в plain text и HTML;
- базовое Markdown-форматирование и общий настраиваемый размер текста;
- однократная тихая проверка GitHub Releases при новом запуске процесса, ручная проверка из меню и безопасная передача нового APK системному установщику Android.

Textory ориентирован на телефон, работает без аккаунта и не требует backend. Проекты изолированы друг от друга: у каждого собственные имя, черновик, последняя сохранённая база, URI и архив версий.

## Приватность

Приложение не содержит телеметрии, не обращается к собственному backend и не выполняет периодический polling. При новом запуске процесса Textory один раз проверяет metadata последнего GitHub Release, только если Android уже видит подтверждённое интернет-соединение. При актуальной версии, отсутствии сети или сетевой ошибке UI не меняется. APK скачивается в приватный cache только после согласия пользователя; ручная проверка также доступна в меню. Общий доступ к накопителю не требуется. Черновики и метаданные находятся в приватных настройках приложения, сохранённые версии — в приватных сжатых файлах. Облачный backup отключён.

## Быстрый старт

Требуются JDK 17 и Android SDK с API 37. Укажите SDK через Android Studio или стандартный `local.properties`, затем запустите:

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Установить его на подключённое устройство можно командой:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Приватный release-ключ намеренно не хранится в репозитории. Подпись настраивается через внешнее защищённое окружение; открытый сертификат и verification fingerprint опубликованы в [руководстве по сборке](docs/BUILDING.md).
